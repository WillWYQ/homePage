> willsleep.dev · 2026-07-05
> 横切规格:管辖所有页面与实验的一切发声行为。隶属 [DESIGN.md](DESIGN.md),冲突时以本文稿为准。

## 1. 三条声学法则

1. **Chrome 永远静音。** 导航、hover、开场、过场、翻牌屏、404——界面层任何元素不发声,永不例外。引入组件自带的音效一律关闭(落位表已有的 `sound: false` 由本法则升格为全站法律)。
2. **声音是仪器,不是装饰。** 全站唯一允许发声的位置是 /lab 的实验内部,且每个声音必须是真实信号:节律、数据、或功能本身。没有"点缀音"。
3. **永远 opt-in,状态永远可见。** 任何声音都由访客在实验内亲手打开;发声期间实验 HUD 常驻一行 mono 读数(`sound: on`),一键(点击或 `m`)即静。默认状态永远是关,刷新即归零(chrome 层永不记忆音频状态;工具型实验可在自己面板内声明后用 localStorage 记住混音参数)。

## 2. 为什么 chrome 必须静音

- **礼仪:** 这栋楼的目标访客在凌晨两点。他们旁边可能有睡着的人。夜里的实验室本来就安静——房间的"空"在听觉上的形态就是无声。
- **物理:** 浏览器 autoplay 策略在用户手势前禁止出声,开场 Vortex 播放时根本没有手势——**开场配乐在 web 上物理不成立**,这个问题被浏览器替我们回答了,不必纠结。
- **预算:** "单次访问几乎察觉不到"的原则下,UI 音效是最刺耳的违例——它在第一次点击就暴露自己。

## 3. 声学身份(当仪器开口时,它听起来像谁)

所有实验的发声共享一套音色法,如同视觉共享单一强调色:

| 维度 | 规格 |
|---|---|
| 音源 | 纯合成(Web Audio 振荡器 + 噪声源 + 滤波),**零采样文件**——不加载任何音频资产,静态导出零负担 |
| 音色 | 正弦/三角波、窄带噪声、低通滤波;禁用锯齿波刺耳段、打击乐、旋律、一切 "UI pop" 质感 |
| 音域 | 基频区 80–400Hz(夜里的声音是低的);所有音高取自同一基频 **A = 110Hz** 的谐波系,实验之间天然和谐 |
| 包络 | attack ≥ 50ms,release ≥ 200ms——夜里的声音没有硬起音;这是"夜里的速度"(§DESIGN 2)的听觉版 |
| 响度 | master gain 上限 0.25;持续声源从静音渐入 ≥1s;绝不出现任何形式的突发响度 |
| 循环 | chrome 层禁止循环(法则 1 已含);实验内循环仅当循环即功能(噪声发生器) |

## 5. 声音实验规格

### the noise floor(白/粉/棕噪声混音台)——旗舰

问题:*多低的噪声地板,能盖住一个睡不着的脑子?*

- 三路噪声(white / pink / brown)+ 一路 60Hz 低通"空调嗡鸣"(实验室的 HVAC),各自推子,mono 刻度。
- **sleep timer:** 15 / 30 / 60 分钟,倒计时结束音量在 ≥60s 内渐出至零——它是真的助眠工具,渐出斜率本身就是设计。
- 混音参数经面板声明后存 localStorage(工具记忆,法则 3 的合法例外);`sound: on` 读数与倒计时常驻 HUD。
- **诚实条款(不许假):** 网页音频在锁屏/切后台时会被系统挂起,面板如实写明:`this instrument sleeps when the screen does.` v1 不做 Media Session 续命,不假装自己是白噪音 App。

### room tone(楼的底噪)——候补

问题:*一栋按夜作息的楼,每个时段听起来是什么样?*

- 与走廊灯况(HOME §4.6)共用五个时段:同一张时刻表,灯暗时嗡鸣更低更稀。视觉的"分时段的灯"与听觉的"分时段的嗡鸣"互为证词。
- 合成配方:低通棕噪 + 110Hz 谐波系的极弱持续音,偶发(泊松分布,分钟级)一声远处的继电器咔哒——全部合成,无采样。
- 依旧只在实验页内、opt-in。楼的声音是展品,不是背景音乐。

## 6. 引擎技术规格(lib/audio.ts)

- **单例 AudioEngine:** 首次 opt-in 手势时创建 AudioContext(自然满足 autoplay 策略);master GainNode 封顶 0.25;所有实验通过它发声,不许自建 context。
- **防爆音:** 一切参数变更走 `setTargetAtTime`/线性 ramp(≥20ms),包括开关——直接 `gain.value =` 赋值在本仓库视为 bug。
- **生命周期:** 离开实验页(路由切换)= 淡出 300ms 后 `suspend()`;`visibilitychange` 隐藏 = 立即 suspend(noise floor 的 sleep timer 例外:挂起但计时逻辑以时间戳结算,回前台对账,不假装后台还在响)。
- **iOS 注意:** 静音拨片对 Web Audio 的作用不可靠,不依赖系统行为——自己的开关必须显眼、必须真关(suspend,不是 gain=0)。
- **reduced-motion 不管音频**(媒体查询无音频等价物),法则 3 的 opt-in 已是更强的保护;不发明 `prefers-reduced-sound`。

## 7. 无障碍与礼仪

- 声音永远不是唯一信息通道:任何声化都与视觉并行呈现(呼吸音 ↔ 波场,噪声 ↔ 推子电平),关掉声音不损失任何内容。
- 发声开关是真按钮(`<button aria-pressed>`),`m` 为实验内静音快捷键,与 `Esc` 返回并列写进实验 HUD 的快捷键行。
- `sound: on` 读数进实验 HUD 的 mono 仪表区,与 EXP 徽标同排;屏幕阅读器经由按钮状态获知,不用 aria-live 轰炸。
- 音量条不做花哨可视化;推子刻度是 mono 数字——它是仪器面板,不是 DJ 台。
