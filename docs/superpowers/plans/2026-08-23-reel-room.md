# /reel 卷带间 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the `/reel` room's content contract, reader, corridor registration, and page —精选(策展式收藏)与日志(时间序流水账)两段式内容,room 保持 `open: false` until real content is authored (matching `notes`/`photos`).

**Architecture:** Follow the `now`/`about`/`lab` content-unit pattern already in `lib/content.ts`: a zod schema in `lib/content-schema.ts` validates frontmatter (mirroring `photoSetSchema`, throwing with a readable issue list on invalid data — this is a hand-authored single-unit file like `about`, not a machine-written manifest like `photos`, but the spec explicitly calls for zod here unlike `now`/`about`'s hand-rolled `toXxx` helpers). `getReel()` reads `content/reel/index.md` via the same `readUnit()` helper `getNow()`/`getAbout()` already use — no directory-override parameter, since nothing else in the codebase needs one for a single hand-authored unit. Empty-branch tests use a temp-write/cleanup technique against the real (currently nonexistent) `content/reel/` path, the same technique `getPhotoRolls` tests use via injectable dirs is unavailable here because `readUnit()` is intentionally not parameterized — see Task 2 for the exact mechanism. `app/reel/page.tsx` mirrors `app/about/page.tsx`'s structure: dual-site gate, `notFound()` on missing/empty content, `RoomShell` wrapper, two conditionally-rendered `<section>` blocks reusing `/now`'s spacing rhythm (`mt-6 space-y-3` inside a block, `mt-24` between blocks) and `/about`'s shelf-item link styling. Cover images are static files under `public/reel/`, rendered with a bare `<img>` like `/lab`'s poster — except reel adds one small client component (`ReelSleeve`) because handling image-load failure (not just absence) requires an `onError` handler, which cannot live in a Server Component.

**Tech Stack:** Next.js App Router (static export), TypeScript strict mode, zod, gray-matter, Vitest.

**Spec:** [docs/superpowers/specs/2026-08-21-reel-room-design.md](../specs/2026-08-21-reel-room-design.md) — the plan argues from this spec; executors should read both. Confirmed judgment calls (spec §4, confirmed 2026-08-23): nav order = append `reel` after `about` (six-word order `now · lab · notes · photos · about · reel`); `RoomStatuses.reel` shape = `{ favorites: number; logEntries: number } | null`.

## Global Constraints

- Content lives only in `content/` — no page/component may hardcode copy that belongs in `content/reel/index.md` or `lib/i18n/strings.ts` (spec §DESIGN 4).
- Red line 3 ("宁缺毋滥"): a room/section with no real content does not render — no placeholder numbers, no empty-but-visible sections. `favorites`/`log` each independently gate their own `<section>`; both empty (or file missing) 404s the whole room.
- Cover images are static files under `public/reel/`, referenced as root-relative paths in frontmatter (`/reel/xxx.jpg`) — **no R2, no sync pipeline**. This was a spec correction (§2); do not wire reel covers into the photos R2 pipeline.
- No audio playback, no play-count/duration numbers — SOUND-DESIGN's three laws and the "不许假" rule both forbid fabricating data the site has no real source for (spec §2/§6).
- No entry pinning in the log section — this was an explicitly rejected structural option (spec §3).
- Dual-site gate: `yueqiao` build must 404 `/reel` without leaking the room name, matching `isWillsleep` + `metadata` double-write pattern already used by `/now` and `/about`.
- `RoomId` is a closed union consumed by several exhaustive-ish `switch`/mapping sites (`components/specimen-shelf.tsx`, `lib/i18n/strings.ts formatPeek`) — every task touching `RoomId` must grep for all consumers and update them, not just the ones spec §1 names explicitly.
- `npx tsc --noEmit` must pass after every task.
- **Not in scope for this plan:** authoring real `content/reel/index.md` content, or populating `public/reel/` with actual cover images. Spec §1 lists the content *contract* (schema/shape) as in-scope, not authored content — same as `notes`/`photos`, which shipped their pipelines with `open: false` and no real content yet. `reel` stays `open: false` after this plan lands; someone (the site owner, in a separate pass) writes the real file later and flips it to `true`.
- **Docs are already synced — do not re-touch them.** `DESIGN.md` §3 (route table) and §10.1 (signature ledger), and `HOME-DESIGN.md` §4.2 (six-word nav note), already have their `/reel` lines committed on `main` (verified 2026-08-23 by reading the files directly — this was done alongside the spec per spec §10's own claim). No task in this plan edits those three files.

```typescript
// reel frontmatter 的 zod schema(spec §2/§3)。精选/日志各自可选——两者皆空是
// 合法的中间状态(page.tsx 据此决定 404,不是 schema 的职责,§1 完成标准)。
// 校验失败直接抛错(getReel() 里做,同 photoSetSchema 的处理):单作者站点,
// 提前发现拼写错误好过悄悄丢内容。

export const reelFavoriteSchema = z.object({
  title: z.string().trim().min(1),
  note: z.string().optional(),
  sleeve: z
    .string()
    .trim()
    .regex(
      /^\/reel\/.+\.(jpe?g|png|webp|svg)$/i,
      "sleeve 必须是 /reel/ 开头的图片路径(如 /reel/xxx.jpg)",
    )
    .optional(),
  href: z.string().trim().url().optional(),
});

export const reelLogEntrySchema = z.object({
  date: z.coerce.date(),
  text: z.string().trim().min(1),
  ref: z
    .string()
    .trim()
    .regex(/^\//, "ref 必须是站内路径,以 / 开头")
    .optional(),
});

export const reelSchema = z.object({
  favorites: z.array(reelFavoriteSchema).optional(),
  log: z.array(reelLogEntrySchema).optional(),
});

export type ReelFrontmatter = z.infer<typeof reelSchema>;
```

```typescript
// ——————————————————————————— /reel 卷带间 ———————————————————————————
// 精选(策展式)与日志(时间序)两段共存(spec §2/§3)。frontmatter 走 zod 校验
// (reelSchema),校验失败直接抛错——同 photoSetSchema 的处理,单作者站点提前
// 发现拼写错误好过悄悄丢内容。两段各自允许为空;是否 404 由调用方(page.tsx)
// 按"两段皆空"判断,不是这个函数的职责。

export type ReelFavorite = {
  title: string;
  note?: string;
  sleeve?: string;
  href?: string;
};

export type ReelLogEntry = {
  date: string;
  text: string;
  ref?: string;
};

export type ReelContent = {
  favorites: ReelFavorite[];
  log: ReelLogEntry[];
};

export function getReel(): ReelContent | null {
  const unit = readUnit("reel");
  if (!unit) return null;

  const result = reelSchema.safeParse(unit.data);
  if (!result.success) {
    const issues = result.error.issues
      .map((i) => `  - ${i.path.join(".")}: ${i.message}`)
      .join("\n");
    throw new Error(`content/reel/index.md frontmatter 校验失败:\n${issues}`);
  }

  return {
    favorites: (result.data.favorites ?? []).map((f) => ({
      title: f.title,
      note: f.note,
      sleeve: f.sleeve,
      href: f.href,
    })),
    log: (result.data.log ?? []).map((l) => ({
      date: l.date.toISOString(),
      text: l.text,
      ref: l.ref,
    })),
  };
}
```

### Task 5: `/reel` page — `app/reel/page.tsx` + `components/reel/reel-sleeve.tsx`

- Produces: the `/reel` route. Nothing downstream depends on this task.

**Why a small client component is needed for the cover image:** spec §5 requires sleeve images to degrade gracefully on load failure, not just absence. Absence is a plain conditional (`{item.sleeve && ...}`). Load failure needs an `onError` handler, and Server Components (this codebase's `app/*/page.tsx` files carry no `"use client"`) cannot attach DOM event handlers. `components/about/placard-flashlight.tsx` is the existing precedent for "one small `"use client"` component for one specific interactive behavior" — `ReelSleeve` follows the same shape.

- [ ] **Step 1: Write `ReelSleeve`**

Create `components/reel/reel-sleeve.tsx`:

```tsx
"use client";

import { useState } from "react";

// 精选卡片的封面图(spec §5):加载失败时优雅降级为纯文字卡,不留破图占位。
// "缺失"由调用方(sleeve 为空就不渲染这个组件)处理;这里只处理"加载失败"——
// 裸 <img> 没有 onError 钩子可挂在 Server Component 里,所以单独拆出这个
// client component(同 placard-flashlight.tsx 的取舍:一个组件只担一件交互)。

export function ReelSleeve({ src }: { src: string }) {
  const [failed, setFailed] = useState(false);
  if (failed) return null;
  return (
    <img
      src={src}
      alt=""
      className="mb-3 aspect-square w-full object-cover"
      onError={() => setFailed(true)}
    />
  );
}
```

```tsx
import { getReel } from "@/lib/content";
import { t, type Locale } from "@/lib/i18n/strings";
import { isWillsleep } from "@/lib/site";

// /reel — 卷带间(docs/superpowers/specs/2026-08-21-reel-room-design.md)。
// 精选(策展式)与日志(时间序)两段独立门控:任一段有内容就渲染,两段皆空
// (或文件不存在)按现有"内容单元不存在"规则 404,与 /now、/about 同构(§1)。
// 签名效果:无(§7)——克制感与 /now、/notes 同源。

// 房间名不外泄到 yueqiao 构建(红线 2 的身份切分):那边这条路由只是一个 404
export const metadata: Metadata = isWillsleep
  ? {
      title: "reel · The Sleep Lab",
      description: "精选与日志:反复回去听的 / 这段时间在听什么",
    }
  : { title: "Not found · Yueqiao Dev" };

export default function ReelPage({ locale = "canonical" }: { locale?: Locale }) {
  if (!isWillsleep) notFound();

  const reel = getReel();
  if (!reel || (reel.favorites.length === 0 && reel.log.length === 0)) notFound();

  return (
    <RoomShell room="reel" locale={locale}>
      {reel.favorites.length > 0 && (
        <section>
          <h2 className="font-mono text-xs text-white/40">
            {t("reel.section.favorites", locale)}
          </h2>
          <ul className="mt-6 space-y-3 font-sans">
            {reel.favorites.map((item, i) => (
              <li key={i}>
                {item.href ? (
                  <a
                    href={item.href}
                    rel="noreferrer"
                    target="_blank"
                    className="group block"
                  >
                    {item.sleeve && <ReelSleeve src={item.sleeve} />}
                    <p className="leading-relaxed text-white/70 underline underline-offset-4 transition-colors duration-200 group-hover:text-white group-focus-visible:text-white">
                      {item.title}
                    </p>
                  </a>
                ) : (
                  <>
                    {item.sleeve && <ReelSleeve src={item.sleeve} />}
                    <p className="leading-relaxed text-white/70">{item.title}</p>
                  </>
                )}
                {item.note && <p className="mt-1 text-white/40">{item.note}</p>}
              </li>
            ))}
          </ul>
        </section>
      )}

      {reel.log.length > 0 && (
        <section className="mt-24">
          <h2 className="font-mono text-xs text-white/40">
            {t("reel.section.log", locale)}
          </h2>
          <ul className="mt-6 space-y-3 font-sans">
            {reel.log.map((entry, i) => (
              <li key={i}>
                <p className="font-mono text-xs text-white/40">
                  {entry.date.slice(0, 10)}
                </p>
                <p className="mt-1 leading-relaxed text-white/70">
                  {entry.text}
                  {entry.ref && (
                    <>
                      {" "}
                      <a
                        href={entry.ref}
                        className="font-mono text-xs text-white/60 underline-offset-4 transition-colors duration-200 hover:text-white hover:underline focus-visible:text-white focus-visible:underline"
                      >
                        {entry.ref}
                      </a>
                    </>
                  )}
                </p>
              </li>
            ))}
          </ul>
        </section>
      )}
    </RoomShell>
  );
}
```
