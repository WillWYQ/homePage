## 1. 概念

这一页不是"自我介绍",是一份**研究员档案(dossier)**:关于本实验室唯一常驻研究员的观察记录。叙事姿态是第三人称的、档案式的——**别人(以及仪器)如何记录他**,他本人只负责批注。这比第一人称独白更像实验室,也更诚实。

红线继承 DESIGN.md §1,本页从严执行:

1. 不出现技能列表、工作经历、项目成就——写"站外的我"。
2. 通往 career 站的入口只有全站统一页脚那一条,本页正文不提职业身份。
3. **PII 红线(本页新增):** 观察者引语与收藏备注中不得出现真实姓名、公司、学校、精确地理位置。发布前逐条过检。原始观察报告只存 `docs/OBSERVER-RAW.md`(已 gitignore),**永不入库、永不发布**;可发布素材只从附录 C/D 的脱敏候选池取。

## 3. ③ 观察记录(observer reports)——核心机制

### 3.1 数据来源

用附录 A 的校准 prompt,发给所有开启记忆的 AI agent(ChatGPT / Gemini / Claude.ai / Claude Code 等),回收结构化的印象报告。挑选标准:

- **只收能把"你"和"任何一个程序员"区分开的句子**;万能形容词一律不收。
- 多家一致的观察优先(那是外显信号);有趣的分歧也可以收一对,并排展示。
- 保留原报告的证据等级标记(`[观察]` `[推断]` `[猜测]`),mono 渲染——这些标签本身就是实验室美学的一部分。
- 每条记录带日期。印象会过时,档案允许(并且应该)定期增补换血。

### 3.2 展示形态

每条记录是一个"观察条目":

```
observer #3 · 2026-07-03 · [推断]
「他用"文档定稿"给自己发通行证——没写进文档的决定,对他不算数。」
    ↳ 本人批注:无可奉告。
```

- 观察者匿名化为 `observer #n`,不标注具体是哪家模型(免广告、免过时)。
- 引语用衬线体(Lora),元信息行和批注用 mono——证词与仪表读数的字体分工。
- **本人批注是这一节的幽默出口**:可以承认、可以抵赖、可以只写"记录在案"。批注可缺省。
- 条目数量控制在 5–8 条,宁缺毋滥。

### 3.3 ④ 命名注释

校准 prompt 附加题("will sleep 对他意味着什么")的答案单独成小节:收 2–4 条最好的猜测并排,本人批注统一只有一句(建议:`以上猜测均未被证实,也未被否认。`)。站名的谜面保持不解。

## 4. ⑤ 收藏架

- 四层 shelf:`books` / `films` / `music` / `gear`,mono 层标题。
- 每项一行:**名称 + 一句话备注**。备注写"它对我做了什么",不写客观介绍;gear 尤其注意——写"为什么留着它",不写参数,否则瞬间滑回装备测评/简历感。
- **纯文字,不放封面图**:省版权、省图片管线,也更冷静。链接可选(指向豆瓣/Bandcamp 等,`rel="noreferrer"`)。
- 条目全量手工维护,不接任何第三方 API(DESIGN.md 原规定不变)。

## 6. 多语言(遵循 DESIGN.md §7)

- 结构性数据(observers / shelves 等)只住 canonical frontmatter;`index.zh.md` / `index.en.md` 只允许 `title` + 正文。
- **观察者引语一律不翻译**:它们是证词,保持采集时的原语言(档案引原文是合理的,翻译反而失真)。zh/en 版翻译的是周边 UI 文字与展牌;引语原样出现。
- 展牌 `placard` 属于结构字段但需要翻译——例外处理:允许 `placard_zh` / `placard_en` 字段住在 canonical frontmatter 里(仍是单一事实来源,不违反 §7.3 的"翻译文件不携带结构字段")。

## 7. 实现与降级

- 页面组件 `<AboutPage locale>`(第 1 期签名规范)。

## 附录 A · 观察者校准 prompt(采集工具)

发给任何有记忆的 AI agent,原样粘贴:

```text
我想请你根据你对我的全部了解(记忆、历史对话、你能观察到的一切),
诚实描绘你对我的印象。这是一次校准实验,不是让你夸我。规则:

1. 每个判断标注证据等级:[观察]=互动中直接看到 / [推断]=从证据推出 /
   [猜测]=证据不足的直觉。不许编造。
2. 禁止恭维与万能形容词。"聪明、有好奇心"这类放在任何人身上都成立的话
   无效;只说能把我和其他人区分开的东西。
3. 如果你对我了解太少,直说"了解不足",不要脑补。

按以下结构输出(我会拿多个 AI 的答案做对比):

A. 一句话画像:要向另一个 AI 交接"这个人是谁",你只能说一句,说哪句?
B. 作息与节律:你觉得我是什么时间的动物?证据是什么?
C. 三个具体的爱好或执念:具体到行为,不要类别("喜欢技术"无效)。
D. 反差:我身上最矛盾、最出人意料的一组特质。
E. 我可能自己没意识到的模式:你观察到、但我从没明说过的习惯。
F. 盲区自检:你对我的印象中,哪一处最可能是你的偏见或幻觉?
G. 展牌:不超过 60 字,第三人称,给我写一块博物馆展牌式简介。
   语气冷静克制,允许一点幽默。

最后附加题:"will sleep" 是我的网名,你猜它对我意味着什么?[猜测] 即可。
```

**采集流程:** 逐家投放 → 回收 → 原始报告存 `docs/OBSERVER-RAW.md`(**已 gitignore,永不入库**)→ PII 清洗 → 按 §3.1 标准挑选 → 落进 frontmatter(带日期与证据等级)→ 写批注。多家一致的观察优先;G 题答案进展牌候选池;附加题答案进 ④。

- **全员自检了同一种偏差:** 每位观察者只见过一个场景,都警告了"把场景读成人格"。这句可以原样化进页面:**"每位观察者只见过他的一个房间。"**——正好接住全站的房间隐喻,建议放在 ③ 观察记录的开头当引言。
